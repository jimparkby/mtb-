# Семья в Moby

Демо детско-семейного банкинга для хакатона МТБанка. Как в [mt-city](https://github.com/jimparkby/mt-city): сверху переключатель ролей (7–13 лет, 14–17 лет, родитель), ниже телефон, где кликается всё.
Стек: React 19 + TypeScript + Vite. Сервер не нужен — всё считается в браузере и сохраняется в `localStorage`.

## Быстрый старт

Нужен **Node.js 22+**.

```bash
npm install
npm run dev        # http://localhost:8080
npm run build      # продакшн-сборка в dist/
```

## Деплой на Vercel

Импортируйте репозиторий: Framework Preset — **Vite**, Build Command `npm run build`, Output Directory `dist` (уже прописано в `vercel.json`).

## Что внутри

```
src/
  App.tsx          демо-панель ролей, телефон, переключение экранов
  store.tsx        общее состояние: балансы, задания, лимиты, операции, навигация
  ui/kit.tsx       шапка, свайп-подтверждение, переключатель, шторка, нижнее меню
  ui/cards.tsx     карусель карт «Откуда / Куда»
  screens/         экраны: главные (родитель, 7–13, 14–17), регистрация, кабинет семьи,
                   перевод, пополнение, оплата, копилка, вклады, карта ребёнка, чат, шторки
public/game/       сборка игры из mt-city (коммит 43dbb0b)
```

## Что работает

- **Родитель:** пополнение (с карты другого банка, наличными, ЕРИП), перевод по номеру карты, платежи (категории, избранные, QR), ответ на просьбу ребёнка, кабинет семьи с вкладками «Задания / Контроль / Операции», регистрация пакета со свайп-договором.
- **7–13:** задания от мамы, MTcoin, копилка, оплата с дневным лимитом и подтверждением мамы, игра Moby.
- **14–17:** кешбэк по уровням карты (`CARD_TIERS` из mt-city), переводы друзьям, вклады, задания, игра.
- Деньги и задания связаны между ролями: принятое мамой задание приходит ребёнку, запрет категории в «Контроле» закрывает её в оплате.

Ставки, комиссии и тексты договора — заглушки в квадратных скобках, их нужно заменить на данные банка.

## Обновить игру

```bash
cd mt-city && npm install && npm run build -w @mt/shared && npm run build -w client
rm -rf ../mtb-/public/game && cp -r apps/client/dist ../mtb-/public/game
```
